# Product Sentiment Analyzer and Review Dashboard – Data Pipeline

This repository contains the **data ingestion and sentiment analysis module** for the *Product Sentiment Analyzer and Review Dashboard* project.

The system processes real product reviews, performs **sentiment analysis using VADER (NLP)**, and generates structured outputs for visualization in a React-based dashboard.

---

##  Features

- Keyword-based product review filtering
- Sentiment classification:
  - Positive
  - Negative
  - Neutral
- Uses real-world review dataset
- Generates CSV output for dashboard visualization
- Ready for API and database integration

---

##  Tech Stack

- Python
- pandas
- VADER Sentiment Analyzer (NLP)
